# My Simple Diary (私の日記帳)

HTML, CSS, JavaScriptだけで構築された、シンプルで使いやすい日記アプリケーションです。ブラウザのLocalStorageを利用するため、サーバー不要で動作し、データはあなたのデバイス内のみに保存されます。

# 📖 利用マニュアル

このセクションでは、日記アプリの使い方を説明します。

## 1. 基本的な使い方

### 日記を書く
1. 左側のカレンダーから、日記を書きたい **日付をクリック** します。
2. 右側の入力エリアで **タイトル** と **本文** を入力します。
3. **「保存する」** ボタンをクリックすると、データが保存されます。

### 気分を記録する
- タイトル入力欄の上にある5つの **絵文字ボタン** から、その日の気分を選べます。
- 保存すると、カレンダー上に選んだ気分の絵文字が表示されます。

### 日記を編集・削除する
- **編集**: カレンダーまたは最近の日記リストから過去の日記を選び、内容を書き換えて「保存する」を押します。
- **削除**: 過去の日記を表示しているときに現れる赤い **「削除」** ボタンをクリックします。

---

## 2. 便利な機能

### 今日へジャンプ
- カレンダーの上部にある **「今日」** ボタンを押すと、一瞬で現在の日付に戻ることができます。

### 日記の検索
- 左側の検索バー（虫眼鏡アイコン）にキーワードを入力すると、過去の日記からタイトルや本文を検索して絞り込めます。

### ダークモード
- 右上の **三日月/太陽アイコン** をクリックすると、見た目をダークモードとライトモードで切り替えられます。

---

## 3. データとセキュリティについて

### データの保存場所
- このアプリは **LocalStorage（ローカルストレージ）** という技術を使用しています。
- 日記のデータは **あなたの使っているブラウザの中だけ** に保存されます。サーバーには送信されないため、プライバシーが守られます。

### バックアップ（エクスポートとインポート）
ブラウザのキャッシュを削除すると日記が消えてしまう可能性があるため、定期的なバックアップを推奨します。

- **エクスポート**: 右上の「エクスポート」ボタンを押すと、現在の日記データをJSONファイルとしてダウンロードできます。
- **インポート**: 右上の「インポート」ボタンを押し、以前ダウンロードしたファイルを選択すると、日記データを復元できます。

---

## 4. トラブルシューティング
- **日記が表示されない**: ブラウザのシークレットモード（プライベートブラウジング）を使用している場合、データが保存されないことがあります。通常のモードでご利用ください。
- **別のデバイスで見たい**: データはデバイス（PCやスマホ）ごとに保存されます。別のデバイスに移動したい場合は、「エクスポート」と「インポート」機能を使ってデータを移してください。

## 🛠 開発と公開
1. このコードを自分の GitHub リポジトリにプッシュします。
2. リポジトリの **Settings** > **Pages** を開きます。
3. **Build and deployment** > **Source** で `Deploy from a branch` を選択します。
4. **Branch** で `main` と `/ (root)` を選択して **Save** をクリックします。
