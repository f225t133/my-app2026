# My Simple Diary (私の日記帳)

HTML, CSS, JavaScriptだけで構築された、シンプルで使いやすい日記アプリケーションです。ブラウザのLocalStorageを利用するため、サーバー不要で動作し、データはあなたのデバイス内のみに保存されます。

## 機能
- **カレンダー連携**: 日付を選んで日記を記録。
- **気分の記録**: その日の気分を5つのアイコンから選択。
- **ダークモード**: 目に優しいダークテーマに対応。
- **検索機能**: 過去の日記をタイトルや内容で検索。
- **データ管理**: JSON形式でのエクスポート・インポート（バックアップ）に対応。
- **レスポンシブ**: スマートフォン、タブレット、PCのすべてのデバイスで利用可能。

## 使い方
1. `index.html` をブラウザで開くだけで開始できます。
2. カレンダーから日付を選び、タイトルと本文を入力して「保存」をクリックします。
3. データのバックアップを取りたい場合は、右上の「エクスポート」からファイルをダウンロードしてください。

## GitHub Pages での公開手順
1. このコードを自分の GitHub リポジトリにプッシュします。
2. リポジトリの **Settings** > **Pages** を開きます。
3. **Build and deployment** > **Source** で `Deploy from a branch` を選択します。
4. **Branch** で `main` (または `master`) と `/ (root)` を選択して **Save** をクリックします。
5. 数分後、提供されたURLであなた専用の日記アプリが公開されます。
